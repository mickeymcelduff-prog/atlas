---
name: triage
description: Process everything in Atlas inbox/ — file each capture into a project, a task, a decision, a delegation, or delete it. Use when I say "triage", "clear my inbox", or the inbox has piled up.
---

For each file or line in `inbox/`:
- **Do it** if it takes under 2 minutes and needs no input from me.
- **File it** as a next action in the relevant `projects/*.md`.
- **Start a project** from `projects/_template.md` if it's multi-step and matters.
- **Delegate it** via the `delegate` skill.
- **Decide it** — if it's a decision, bring me options + recommendation, then log in `decisions/`.
- **Drop it** if it doesn't serve a priority — list what you dropped so I can object.

Finish with a one-screen summary, then commit and push.
