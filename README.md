# Atlas

My personal operating system and home base for my Chief of Staff agent.
Plain Markdown in a private GitHub repo, so it works the same at home, at work, and on any device.

## Use it

```powershell
cd ~/atlas
claude
```

Then: `/daily-brief`, `/triage`, `/delegate`, `/weekly-review` — or just talk to it.
`CLAUDE.md` is loaded automatically and makes Claude act as chief of staff in this folder.

## New machine setup

```powershell
git clone https://github.com/<you>/atlas.git $HOME\atlas
```

Sync any time with `.\scripts\sync.ps1`.
